Development

Built carefully. Tested in real workflows.

DraftFlow is an independently developed Windows desktop application currently in private testing with the developer's own Etsy shop.

  • Implemented: Etsy OAuth 2.0 connection, listing selection, draft creation, photo replacement, and batch processing.
  • Tested: Draft creation and photo-management workflows using the Etsy Open API.
  • Current focus: Security improvements, commercial-access preparation, and multi-user architecture.
  • Planned: Public Windows release, a web-based application, and optional subscription plans.

DraftFlow is not currently available for public download. Commercial availability is subject to Etsy access approval, further development, security review, and testing.

The current implementation focuses on digital listings. Digital download files are not copied automatically and must be attached separately by the seller.

Privacy & Security

Designed with seller control in mind.

The current private-testing version uses Etsy OAuth 2.0 to authorize access to the developer's shop. Original listings remain unchanged, and created listings stay as drafts.

The planned commercial platform will require additional account security, protected credential storage, and documented data-handling procedures before external sellers are onboarded.

A full privacy policy describing commercial customer data processing will be published before public launch.
