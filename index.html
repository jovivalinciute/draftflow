DraftFlow

Spend less time preparing product listings.

DraftFlow is a Windows desktop application in development designed to help online sellers organize product images and prepare multiple draft listings efficiently.

Planned Features

  • Create multiple draft listings from an existing listing.
  • Organize product images using numbered files or folders.
  • Replace all, replace selected, or add listing photos.
  • Preview listing batches before processing.
  • Keep listings as drafts without automatic publishing.

Development Status

DraftFlow is currently in early development. Its local draft preparation and preview functionality is being tested. Etsy API integration is planned, subject to approval and technical validation.
